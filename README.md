# LeetCode AI Solver

一个的 LeetCode 自动刷题JS脚本。可以读取题目与当前编辑器模板，通过兼容 OpenAI API 格式的模型生成代码，填入编辑器并提交判题；判题失败时会自动携带错误信息重试。

支持 `leetcode.com` 和 `leetcode.cn`，并提供可视化管理面板。

## 功能特点

- 自动读取题目描述、编程语言和代码模板
- 调用 OpenAI 或兼容其接口格式的模型生成代码
- 自动填入 LeetCode Monaco 编辑器并提交判题
- 判题失败后将错误详情反馈给模型并自动重试
- 支持连续刷题和仅解当前题两种模式
- 支持配置重试次数、判题超时和题目切换间隔
- 内置悬浮管理面板、运行日志和统计信息
- 配置保存在油猴脚本的浏览器存储中

## 使用说明

### 环境要求

- Tampermonkey、Violentmonkey 等用户脚本管理器
- 支持 OpenAI Chat Completions 格式的 API
- 可用的 API Key
- 现代浏览器

### 安装脚本

1. 安装浏览器油猴插件，例如 Tampermonkey。
2. 打开仓库中的 [`ai_auto_solver_user.js`](https://github.com/locherli/leetcode-ai-solver/blob/main/ai_auto_solver_user.js)。
3. 将脚本内容复制到油猴脚本编辑器并保存。
4. 打开任意 LeetCode题目页面，脚本右下角会显示“AI 自动刷题”悬浮按钮。

## 配置

点击右下角悬浮按钮打开管理面板，填写以下配置：

| 配置项 | 说明 | 默认值 |
|---|---|---|
| API Base URL | OpenAI 兼容接口地址 | `https://api.openai.com/v1` |
| API Key | 模型接口密钥 | 空 |
| Model | 使用的模型名称 | `gpt-4o` |
| Temperature | 模型生成随机性 | `0.2` |
| 最大重试次数 | 当前题目判题失败后的重试次数 | `3` |
| 判题等待超时 | 等待判题结果的最长时间 | `20000 ms` |
| 下一题间隔 | 提交成功后切换题目的等待时间 | `2500 ms` |
| 重试耗尽后跳过 | 达到重试上限时自动进入下一题 | 开启 |
| 页面刷新后恢复 | 刷新页面后尝试恢复连续刷题 | 关闭 |
| System Prompt | 指定模型的解题规则 | 内置竞赛专家提示词 |

配置完成后点击“保存配置”。也可以先点击“测试连接”，确认接口可用。

## 开始运行

进入题目页面并打开管理面板：

- **仅解当前题**：只处理当前题目。
- **启动连续刷题**：处理当前题目，通过后自动进入下一题。
- **停止**：中止当前任务和正在进行的 API 请求。

脚本运行时会：

1. 读取题目描述与当前代码模板。
2. 调用模型生成完整代码。
3. 将代码填入编辑器。
4. 提交代码并等待判题结果。
5. 未通过时提交错误详情，请模型修复并重试。
6. 通过后等待设定时间并进入下一题。

管理面板还会显示已通过、纠错重试、失败/跳过等统计数据及运行日志。
